# 💊 AI Фармацевт — консольная аптечка на Kotlin

Мини-проект №1: программа-аптечка, в которой собрано всё пройденное по Kotlin.
Настоящего AI и камеры нет — «сканы» изображены кодом, логика как в мобильном приложении.

## Что умеет

| Функция | Как сделано |
|---|---|
| Хранит лекарства: название, количество, единица, срок годности (месяц.год) | `data class Medicine`, `mutableListOf` |
| Показывает аптечку с заголовком | функция `showKit(kit, title)`, `forEach`, строковые шаблоны |
| Находит просроченные | `filter` + функция `dateNum` (год × 12 + месяц) |
| Сортирует по сроку годности | `sortedBy { dateNum(it) }` |
| Добавляет лекарство и выбрасывает просроченные | `add`, `removeAll` |
| Сканы и квоты: Free — 3, PRO — 50 | `Map`, `?:`, `repeat`, `if` |

## Как запустить

Скопировать [Main.kt](Main.kt) в [Kotlin Playground](https://play.kotlinlang.org) и нажать ▶.

## Решения по ходу проекта

- Единица измерения — отдельное свойство `unit`: у лекарств бывают упаковки, пакетики, флаконы, блистеры. `count` остаётся числом, чтобы с ним можно было считать.
- Срок годности хранится как месяц и год. Чтобы сравнивать даты, они переводятся в одно число: `год * 12 + месяц`. Сравнивать только месяцы нельзя: 09.2027 позже, чем 11.2026.
- Формула даты повторялась трижды — вынесена в функцию `dateNum` (рефакторинг: вывод не изменился).
- Сокращения «уп.», «пак.» вместо полных слов — чтобы не склонять («1 пакетик», «2 пакетика»).
